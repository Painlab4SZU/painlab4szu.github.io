# Painlab4SZU — research group website

[Visit the website](https://painlab4szu.github.io/) · [Google Scholar](https://scholar.google.com/citations?user=khAJJ2gAAAAJ) · [Faculty profile](https://psy.szu.edu.cn/info/1101/1477.htm)

Pain and cognitive neuroscience at Shenzhen University. The website introduces the group's research interests, selected publications, research lead, and academic contact information.

## 更新网站

- `index.html`：网站正文、样式、中英文文案与论文列表。正文内的 `.paper` 是静态论文条目；`translations` 包含中英文界面文案。
- `lab-mark.svg`：临时使用的原创神经信号标识，可替换为正式课题组标识。
- `profile-banner.svg`：GitHub 账号介绍页横幅。
- 发布来源为 `main` 分支根目录。通过 GitHub 修改并提交文件后，Pages 会自动部署。
- 新增论文时，同时更新论文条目的 `data-year`、`data-topics`、年份下拉选项，并核对 DOI 和作者信息。

## 内容来源与边界

此版本是课题组展示页初稿，参考 CANlab 的学术信息布局，自行编写页面与标识，没有复制 CANlab 的研究成果、品牌或源代码。论文列表是精选，非完整清单；历史论文列为彭微微及合作者的工作，不暗示所有作者均为当前课题组成员。当前不列未经确认的团队成员、引用指标、招募信息或尚未发布的代码工具。

姓名、职称、单位与研究简介参考[深圳大学心理学院教师主页](https://psy.szu.edu.cn/info/1101/1477.htm)；论文从用户指定的 [Google Scholar 主页](https://scholar.google.com/citations?user=khAJJ2gAAAAJ)选择，并与出版商或 PubMed 记录核对。核对日期：2026-10-21。
